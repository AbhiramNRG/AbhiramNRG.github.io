Build 01 · Arduino

Morse Code Password Lock

A sound-activated lock that listens for short and long sounds and translates them into Morse code dots and dashes in real time. After a brief pause, the Arduino checks the sequence against a stored password. The LCD shows the code as it's entered and then displays "Access Granted" or "Try Again," while LEDs and a buzzer give distinct success and error signals.

Arduino UnoHW-485 sound sensorI2C LCDPassive buzzerLEDs
Build 02 · Arduino

RFID Access Control System

A card-based door entry system. Scanning an RFID card reads its unique ID, which the Arduino checks against an authorized ID. A valid card triggers "Access Granted" and drives a stepper motor to open the lock. LEDs and buzzer beeps give instant feedback, and every scan is logged to the serial monitor.

Arduino Uno R4 WiFiRFID readerStepper motorBuzzerC++
Build 03 · Arduino + Processing

Ultrasonic Radar with Live Display

A servo motor sweeps an ultrasonic sensor across a range of angles, and the sensor times its echo pulses to measure the distance to nearby objects. The Arduino streams each angle and distance reading to my laptop, where a radar display draws detected objects live. I adapted the HowToMechatronics radar display in Processing and added automatic serial-port detection.

Arduino UnoUltrasonic sensorServo motorProcessingSerial comms
Build 04 · Arduino + Wi-Fi

Smart Irrigation System

A Wi-Fi plant monitor that waters the plant automatically. A soil moisture sensor tracks how dry the soil is. When moisture drops below 40%, the Arduino switches a water pump on through a relay. The board also hosts a web page that shows live moisture and pump status, with buttons to turn the pump on or off.

Arduino Uno R4 WiFiSoil moisture sensor2-channel relayWater pumpWeb server
